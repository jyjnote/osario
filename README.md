# 🖼️ A way Trip

**작가와 대화하듯 예술을 이해하는 인터랙티브 AI 도슨트 시스템**  
㈜오사리오 | 2024 ICT이노베이션스퀘어 성과공유회 전시작

---

## 🚀 프로젝트 개요

"A way Trip"은 박물관/미술관 관람객이 **작가 캐릭터와 직접 대화하는 몰입형 관람 경험**을 제공하는 AI 기반 해설 시스템입니다.  
관람객의 질문을 실시간으로 인식하고, AI가 이에 맞는 작가 캐릭터의 음성 및 영상 답변을 제공합니다.

---

## 💡 주요 기능

| 기능 | 설명 |
|------|------|
| 🎤 실시간 음성 인식 | 관람객의 질문을 STT(Speech to Text)로 변환 |
| 🧠 우선순위 기반 답변 매칭 | 질문 내용에 따라 적절한 해설 영상 검색 |
| 📺 투명 디스플레이 출력 | 캐릭터가 투명 디스플레이를 통해 해설 |
| 👨‍🎨 작가 페르소나 구현 | 반 고흐, 다빈치, 달리, 허백련 등의 성격·목소리·외형을 AI로 구현 |
| 🔁 양방향 인터랙션 | 관람객과 작가 간 1:1 대화 구조 지원 |
| 🌐 다국어·다채널 확장성 | 다양한 언어, 다양한 전시에 맞춰 확장 가능 |

---

## 🧱 시스템 구성

- **AI 파트**: STT → 질문 분류 → 콘텐츠 검색 → 실시간 응답
- **프론트엔드**: NUI, 캐릭터 인터페이스, 몰입형 UX
- **하드웨어**: 투명 디스플레이 + 음성인식 마이크 + 스마트 센서

---

## 📊 시장성과 수요

- 국내 박물관·미술관 1,200여 곳
- 연간 10만 명 이상 관람 박물관 150여 곳 대상
- **Z세대**와 **디지털 전시 확산**을 반영한 미래형 서비스
- 광주 의재미술관, 더현대 등과 협업 추진 중

---

## 🏆 비교 우위

- 기존 일방향 오디오 해설기 대비 **2배 빠른 응답 속도**
- 관람객 질문에 맞춤형 해설 제공 (30초 이내)
- **100% 작품 데이터화**, **99.9% 작가 재현도**
- 월 사용 비용 약 160만원으로 **가격 경쟁력 확보**
